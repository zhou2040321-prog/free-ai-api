## Credits and usage

- 50 in-site API credits on signup.
- 0.01 rate multiplier for the GPT group.
- No daily usage cap under the stated rules, plus free credits for daily check-ins.
- No top-up entry or payment required.

**Why only 50 credits at signup?** This is not a paid trial or a prompt to top up later. The limit is there to discourage casual sign-ups, bulk registrations, and abuse, so limited free resources can go to people who actually need them. Users are not expected to pay when the credits run out.

API calls deduct credits from your balance. Available credits, concurrency, and model availability depend on the site's current settings.

## Before you use it

Please do not abuse the service, register accounts in bulk, or resell invitation codes.

A complete privacy policy has not been published yet. It is not clear whether request content, model responses, and tool-call records are retained, shared, or used for other purposes. For now, use only your own non-sensitive test data. Do not submit private code, sensitive personal information, trade secrets, or credentials.

This is an independent third-party gateway, not an official service of any model provider.

If something doesn't work, ask in the QQ group or open an Issue. Please remove API keys and private information before posting.

If you find the project useful, feel free to Star it so you can find it again.
