# AI 福利站使用教程

网站：[apifuli.com](https://apifuli.com) · QQ 群：1131913173

本站使用 Sub2API 面板。以下是普通用户的接入流程，不需要自行搭建服务器。

目前网站尚未公开完整隐私政策。请先用自己的非敏感测试数据验证接口，不要提交私有代码、个人敏感信息、商业秘密或凭据。

## 1. 注册账号

进 QQ 群领取免费邀请码，再到官网注册并登录。

## 2. 创建 API 密钥

1. 点击左侧「API 密钥」。
2. 点击右上角「创建密钥」。
3. 名称随便填一个自己认得的名字，例如 Codex。
4. 需要使用 GPT 模型时，选择 GPT 分组（站内显示 0.01x）。
5. 创建后复制自己的 API Key，妥善保存。

不要把完整密钥发到群里或提交到 GitHub。

## 3. 获取接入配置

回到 API 密钥列表，在新建密钥右侧点击「使用密钥」。按弹窗选择客户端及操作系统，复制站点实际生成的接入地址、密钥和配置。

不要把其他 Sub2API 网站的域名照搬进自己的客户端，也不要自行重复拼接 /v1。

## 4. 用 CC Switch 或 Cockpit Tools 接入 Codex

### CC Switch

如果已经安装 CC Switch：

1. 在网站的密钥操作列点击「导入到 CCS」。
2. 按客户端提示确认供应商及接入地址。
3. 保存并启用这份配置。
4. 重新打开 Codex。

若自动导入失败，可在 CC Switch 手动添加供应商，填写网站「使用密钥」给出的 Base URL 和自己的 Key。

### Cockpit Tools

如果使用 Cockpit Tools：

1. 进入左侧 Codex 页面。
2. 点击账号列表旁边的加号，打开「添加 Codex 账号」窗口。
3. 切换到 API Key 选项。
4. 根据当前版本的字段填写供应商名称（例如 AI 福利站）、站内生成的 API 地址和自己的密钥；协议与模型按「使用密钥」提供的配置选择。
5. 保存后切换到刚添加的账号，再打开 Codex。

具体字段和按钮可能随客户端版本变化。Codex 需要相应的接口协议，本站的实际兼容性以接入测试为准。

## 5. 测试是否成功

在客户端新建测试会话，只发送一条简单的非敏感消息，例如 `hi`。

如果收到正常回复，再回网站的「使用记录」检查是否出现刚才的请求。这样可以确认客户端确实在使用本站，而非其他已配置的供应商。

## 常见问题

| 情况 | 先检查什么 |
| --- | --- |
| 401 | 密钥是否填错、是否有效 |
| 403 | 当前账号及分组是否有调用权限 |
| 404 | 接入地址、接口协议、模型是否匹配 |
| 429 | 并发、速率限制或上游容量 |
| 无法回复 | 当前供应商是否启用，重启客户端后再试 |

遇到问题可在 QQ 群反馈。截图或日志请先去掉完整 API Key 和私人信息。
